SmartPay CRM v3.10.45 — Умные напоминания

Нужно заменить только index.html.
Code.gs менять не нужно.

Что добавлено:
- Умные напоминания в центре уведомлений.
- Если у мерчанта 7+ дней нет комментария или задачи — появляется напоминание “Нужно связаться”.
- Если 14+ дней нет комментария или задачи — появляется важное/красное напоминание.
- Напоминание показывается ответственному менеджеру, а администратор видит по всем.
- В уведомлении есть действия: Открыть, Комментарий, Задача, Отложить 3д.
- Поддерживается мобильная версия и тёмная тема.

После замены index.html сделайте Ctrl + F5.
