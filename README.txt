SmartPay Merchant CRM v3.11.00 — Sales Control

Что добавлено:
1. План / Факт по менеджерам по месяцам:
   - новые мерчанты;
   - договоры;
   - запуски / активации.
2. Журнал взаимодействий с мерчантом:
   - звонок;
   - встреча;
   - Telegram;
   - Email;
   - презентация;
   - другое;
   - результат;
   - следующее действие и дата.
3. Блок «Мой день / Сегодня»:
   - задачи на сегодня;
   - просроченные задачи;
   - мерчанты, с которыми нужно связаться;
   - мерчанты без активности 7+ дней.
4. Защита от дублей:
   - проверка ИНН;
   - проверка телефона;
   - предупреждение о похожем названии;
   - серверная дополнительная проверка.
5. Источник привлечения мерчанта + аналитика.
6. Причина потери мерчанта + аналитика.
7. Для факта запусков добавлено поле activatedAt, которое фиксируется при первой активации.

Не изменялось:
- импорт из Excel;
- контроль срока договора;
- Merchant Health Score;
- транзакционные данные SmartPay;
- Telegram token / Chat ID / Telegram-настройки.

Установка:
1. Заменить Code.gs на Code_v3.11.00.gs.
2. Заменить index.html на index_v3.11.00.html.
3. Развернуть новую версию Google Apps Script Web App, если используется deployment.
4. Обновить CRM через Ctrl+F5.

При первом обращении backend автоматически создаст листы:
- ManagerPlans
- MerchantInteractions

А в лист «Главная» автоматически добавятся недостающие колонки:
- leadSource
- lossReason
- activatedAt

Существующие данные сохраняются.
