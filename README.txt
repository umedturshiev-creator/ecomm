Добавлено:
- всплывающее уведомление при создании нового мерчанта;
- всплывающее уведомление при изменении статуса мерчанта;
- системное уведомление браузера на мониторе при выданном разрешении;
- кнопка включения всплывающих уведомлений в Центре уведомлений;
